## 👨‍💻 About Me

I'm a **Unity Game Developer** with a Software Engineering background, focused on building **modular, maintainable, and scalable gameplay systems** using Unity and C#.

My primary interests include gameplay programming, game AI, and software architecture, with an emphasis on clean code, efficient algorithms, and well-structured systems designed for long-term scalability.

- 🎮 **Gameplay Programming:** Developing player controllers, combat mechanics, weapon systems, abilities, and interactive gameplay features
- 🤖 **Game AI:** Implementing AI behaviors using Finite State Machines (FSM), pathfinding, Behavior Trees, and decision-making algorithms
- 🏗️ **Software Architecture:** Applying OOP, SOLID principles, ScriptableObjects, and design patterns to create modular gameplay systems
- ⚙️ **Performance Optimization:** Improving runtime efficiency through algorithmic optimization, profiling, and performance-conscious development
- 🧠 **AI & Emerging Technologies:** Exploring advanced game AI, procedural generation, and Machine Learning fundamentals
